I tested the new skills ([`ai-patterns-skills`](https://github.com/fnzko/just-right-rust/tree/30ce8a2dc937d1adb5c3bf0f6d5e724fae99c2ff/skills)) by letting agents work alone, headless, with and without them. 16 refactors of the aws-emulator SQS crate, then 87 runs on a small queue service with hidden acceptance tests, each reviewed blind. Short version: the skills help when the agent writes new code, they do nothing on existing code unless something tells it what to look for, and nothing I tried changed how it adds a feature.

Everything is in [this repo](https://github.com/OWNER/REPO): [one-page summary](https://github.com/OWNER/REPO/blob/33de27e42b2f791b3a3072376553dba00ea7e471/SUMMARY.md) (Spanish), [full report](https://github.com/OWNER/REPO/blob/33de27e42b2f791b3a3072376553dba00ea7e471/v2/REPORT.md), [log of the first trial](https://github.com/OWNER/REPO/blob/33de27e42b2f791b3a3072376553dba00ea7e471/TRIAL-LOG.md).

All 87 runs of the second trial pass the hidden tests, so no gain came at the cost of behavior. Scores compare only inside one stage.

## What I would change

- Add a short entry skill with the six review checklists ([the one tested](https://github.com/OWNER/REPO/blob/33de27e42b2f791b3a3072376553dba00ea7e471/v2/arms/short/skills/rust-rules/SKILL.md)) and keep the guides as reference.
- Add an audit skill for clean-up and review requests ([the one tested](https://github.com/OWNER/REPO/blob/33de27e42b2f791b3a3072376553dba00ea7e471/v2/arms/audit/skills/rust-audit/SKILL.md)).
- Reword [this line](https://github.com/fnzko/just-right-rust/blob/30ce8a2dc937d1adb5c3bf0f6d5e724fae99c2ff/skills/rust-keep-it-simple/SKILL.md#L191) of `rust-keep-it-simple`: "Do not rewrite working code elsewhere to match them" tells an agent doing a refactor to do nothing.
- Use hooks as a detector that hands findings back before the agent finishes ([the one tested](https://github.com/OWNER/REPO/blob/33de27e42b2f791b3a3072376553dba00ea7e471/v2/arms/hook/hooks)).

Adding a feature to code written in another style is unsolved.

## Limits

Two or three runs per cell, one kind of service, small crates in the second trial, reviewers and authors from the same model family, no human review, and the texts of the arms were written for this trial. 82 of 85 repeated blind scores differ by one point or less ([reliability](https://github.com/OWNER/REPO/blob/33de27e42b2f791b3a3072376553dba00ea7e471/v2/REPORT.md?plain=1#L2263)).

# Working on Rust code

Before writing or changing Rust code, load each of these skills:

- `rust-domain-types`
- `rust-error-discipline`
- `rust-ownership`
- `rust-keep-it-simple`
- `rust-comments`
- `rust-test-quality`

Apply them while you work, and run each skill's review checklist on your diff before you finish.

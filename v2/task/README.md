# miniq task fixture (trial v2)

- `SPEC.md`: the task handed to the agent (build miniq from scratch). `SPEC-feature.md`: the follow-up feature request (batches, queue tags, `MaxMessageBytes`). Both describe behavior only.
- `acceptance.py`: the hidden black-box tests, Python 3 standard library only: `python3 -I acceptance.py <miniq binary> [--feature] [--json] [-k SUBSTRING]`. One fresh process per scenario, 10 s timeout each, exit 0 only if all pass.
- Scenario counts: 58 for `SPEC.md`; `--feature` adds 22 (80 in total). With `--feature` every `GetQueueAttributes` must show `MaxMessageBytes`, so pass the flag exactly when the crate implements `SPEC-feature.md`.
- `reference/`: the oracle crate (binary `miniq`, depends on `serde_json` only). `cargo build` gives base plus feature: 80/80 with `--feature`. `cargo build --no-default-features` gives the base spec alone: 58/58 without the flag. `target/` was removed to save disk.
- How it was validated: both builds pass; the Python model inside `acceptance.py` (it produces the expectations of the two stress scenarios) agreed with the reference on 750 random 1500-command scripts; 53 mutations of the reference were each caught by at least one scenario.
- Three scenarios feed 100000 or more lines (`message_limit_standard`, `message_limit_fifo`, `batch_send_message_limit`); the reference debug build takes 1 to 1.5 s for each. An implementation that rescans a queue on every command times out there; `SPEC.md` states the expectation.
- Left unspecified on purpose and not tested: repeated member names, odd number spellings such as `-0`, lone surrogate escapes, the clock past 4000000000, `null` values inside `Tags`.
- Stated in the spec, tested, but easy to read the other way: in `CreateQueue` a bad name beats attribute errors while attribute errors beat the `.fifo`/`Fifo` mismatch; explicit and content-based deduplication ids share one id space; a handle of another queue's message is `ReceiptHandleExpired`, not `ReceiptHandleInvalid`; a delivery with visibility timeout 0 yields a handle that never works; batch shape errors come after `QueueDoesNotExist`; blank input lines get an `InvalidRequest` response.
